# UI reference notes

The two supplied Zalith Launcher 2 screenshots are treated as layout inspiration only.

VANTA carries forward the useful visual ideas:
- Landscape-first launcher canvas.
- Strong profile/character area on the home screen.
- Account list with a visible active state.
- Large, high-contrast primary action.
- Compact icon actions in the top bar.
- Dark graphite panels and rounded corners.

VANTA changes the visual identity:
- VANTA wordmark and product naming.
- Charcoal surfaces, neutral borders, white typography, and a restrained mint accent.
- Native Compose layout and transitions.
- No Zalith logos, proprietary artwork, or copied UI assets.
