MASTER DEVELOPMENT PROMPT — NEXT-GENERATION ANDROID MINECRAFT JAVA LAUNCHER

1. PROJECT IDENTITY

You are a senior Android software engineer, game launcher developer, UI/UX designer, graphics engineer, and build engineer.

Your task is to design and develop a COMPLETE, FUNCTIONAL, production-oriented Android Minecraft Java Launcher.

The application must be inspired by the functionality, usability, and overall experience of Zalith Launcher 2, but it must have its own original identity, branding, visual language, icons, layouts, and implementation.

This is NOT a website.
This is NOT a WebView application.
This is NOT a static UI prototype.
This is NOT a fake Minecraft launcher.

It must be a genuine Android APK capable of installing, configuring, and launching Minecraft Java Edition on compatible Android devices.

The project must prioritize real functionality, clean architecture, responsive performance, and a premium visual experience.

Primary target

- Platform: Android.
- Architecture: ARM64 (aarch64).
- Minimum target: Android 8.0+, subject to dependency compatibility.
- Primary test device: Android 15, ARM64.
- Orientation: LANDSCAPE.
- Development environment: GitHub repository and GitHub Actions.
- Build output: Installable APK.
- UI language: ENGLISH ONLY.
- Application category: Minecraft Java Launcher.

Do not create a PC-only application.

The launcher must be designed specifically for Android touchscreen devices.

23. BACKGROUND GAME PERSISTENCE

This feature is extremely important.

The user must be able to:

1. Launch Minecraft Java.
2. Press the Android Home button.
3. Open another application.
4. Return to the launcher.
5. Resume the existing Minecraft process if it is still alive.

The launcher must not automatically terminate Minecraft merely because the launcher UI is no longer visible.

Investigate Android lifecycle behavior, foreground services, process management, and the requirements of the selected Minecraft engine.

Implement an appropriate background execution strategy.

Important limitations:

- Android may pause or throttle background applications.
- Android may reclaim memory and terminate processes.
- Battery optimization may affect background execution.
- A foreground service does not guarantee unlimited execution.
- Multiplayer disconnection may still occur if the process or network is interrupted.

When possible, preserve the game process and its rendering context.

When the process has been terminated, detect that condition and provide a safe recovery path.

Do not claim that a terminated Minecraft session can always be resumed exactly where it stopped.
